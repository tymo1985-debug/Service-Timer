# Учёт служения — PWA

## Как выпустить новую версию

Проверка обновлений сравнивает версию, «зашитую» в `index.html`, с версией в `version.json` на сайте.
Поэтому при каждом новом деплое нужно поднять номер **в двух местах**:

1. В `index.html` найдите строку:

   ```js
   var APP_VERSION = "1.0.0";
   ```

   и поставьте новый номер, например `"1.0.1"`.

2. В `version.json` поставьте **тот же** номер и опишите изменения:

   ```json
   {
     "version": "1.0.1",
     "buildDate": "2026-08-15",
     "downloadUrl": "",
     "releaseNotes": [
       "Что изменилось — пункт первый",
       "Что изменилось — пункт второй"
     ]
   }
   ```

   `downloadUrl` можно оставить пустым — тогда приложение перезагружается по своему же адресу.
   Заполняйте его, только если приложение переезжает на другой адрес.

   Приложение само проверяет `version.json` при запуске и далее раз в сутки (при наличии интернета),
   поэтому после деплоя пользователь увидит уведомление о новой версии без ручной проверки.

3. Залейте все файлы на GitHub Pages (или любой другой хостинг) как обычно.

Важно: номера должны совпадать. Если в `version.json` номер выше, чем в `index.html`,
приложение предложит обновиться. Если совпадают — скажет, что установлена последняя версия.

Формат номера — числа через точку (`1.0.0`, `1.2.10`). Сравнение идёт по числам,
поэтому `1.2.10` считается новее, чем `1.2.9`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Само приложение (весь код в одном файле) |
| `version.json` | Версия, опубликованная на сайте — источник правды для проверки обновлений |
| `manifest.json` | Манифест PWA (имя, иконки, цвета) |
| `service-worker.js` | Офлайн-кеш. При изменении файлов поднимайте `CACHE_NAME` |
| `icon-*.png`, `favicon.png`, `apple-touch-icon.png` | Иконки |

## Данные пользователя

Записи и настройки хранятся в `localStorage` браузера на телефоне.
Обновление приложения **не удаляет** их: очищается только кеш файлов, а не данные.
Для переноса на другое устройство используйте «Резервная копия» в настройках.
